# Panduan Pegawai

Buku panduan kepegawaian versi web untuk perusahaan dan lembaga pendidikan di Indonesia. Isinya mengacu pada peraturan ketenagakerjaan yang berlaku per Oktober 2026, termasuk catatan masa transisi menuju UU Pelindungan Ketenagakerjaan.

Disusun oleh **Ahmad Dawami** · Bogor, 25 Oktober 2026

## Isi

- 24 bab (Bab 0–23) dan 10 lampiran
- Hubungan kerja, waktu kerja, cuti, pengupahan, komponen gaji dan tunjangan, jaminan sosial, pensiun, K3, kode etik, disiplin, PHK, hubungan industrial
- Bab khusus lembaga pendidikan (guru, dosen, tenaga kependidikan)
- Templat surat, contoh struktur organisasi, tabel UMP 2026, daftar kontak, dan daftar periksa transisi

## Fitur

- Daftar isi interaktif dan penanda bab aktif
- Pencarian isi buku (tekan `/` atau `Ctrl+K`)
- Indikator progres membaca, navigasi bab sebelumnya/berikutnya
- Kalkulator pesangon, kompensasi PKWT, THR, lembur, dan gaji bersih
- Kolom nama lembaga untuk personalisasi
- Responsif untuk ponsel, tablet, dan desktop; mendukung mode gelap

## Menjalankan

Tidak perlu instalasi. Buka `index.html` di peramban, atau tayangkan lewat GitHub Pages:

1. Buka **Settings → Pages** di repositori ini.
2. Pada **Source**, pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/ (root)`, lalu **Save**.
4. Situs akan tersedia di `https://<username>.github.io/<nama-repo>/` dalam beberapa menit.

## Catatan

Buku ini adalah pedoman umum, bukan nasihat hukum. Ketentuan dapat berubah setelah UU Pelindungan Ketenagakerjaan diundangkan dan peraturan pelaksananya terbit. Untuk kasus tertentu, konsultasikan dengan dinas ketenagakerjaan setempat atau konsultan hukum ketenagakerjaan.
